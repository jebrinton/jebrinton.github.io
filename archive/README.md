# archive/

Old pixel-art site files, archived during the June 2026 overhaul.

These files are dead. The new site is generated by `site_src/build.py` from
`site_src/content/*.md` markdown files and Jinja2 templates.

Files archived here:
- `index.html` — old hero page
- `about.html` — old about page (YAML-driven, replaced by site_src/content/about.md)
- `offline.html` — old Questdex / offline page (replaced by site_src/content/offline.md)
- `offline-fieldnotes.html` — old offline fieldnotes page
- `photography.html` — old gallery page (superseded by travels.html)
- `css/` — old stylesheets (style.css, offline.css, offline-fieldnotes.css)
- `js/` — old scripts (hero.js, typer.js, offline.js, gallery.js, nav.js)

Do not reference anything in this directory from live pages.
